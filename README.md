# Dr. Sudan Puri — Personal Website

A full-stack personal website for Dr. Sudan Puri, General Practitioner.

## Tech Stack
- **Frontend**: Next.js 14 + Tailwind CSS v4 + TypeScript
- **Backend**: Node.js + Express.js + TypeScript
- **Database**: MongoDB + Mongoose
- **Real-time**: Socket.io
- **Auth**: JWT + bcrypt

## Project Structure
dr-sudan-puri/
├── frontend/ ← Next.js app
└── backend/ ← Node.js API

## Getting Started

### Backend
```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

### Frontend
```bash
cd frontend
npm install
cp .env.example .env.local
npm run dev
```
